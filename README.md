# Shop Manager (MERN)

A full-stack application for managing:

- Products & Inventory
- Customers
- Orders (Sale + Rental)
- Payments
- Dashboard analytics

## Tech Stack

- Frontend: React + Vite + Tailwind
- Backend: Node.js + Express
- Database: MongoDB

## Run Locally

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
